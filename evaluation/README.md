# Evaluation workspace

This directory holds evaluation assets for supported repository quality workflows. The legacy direct-Runtime V2 endpoint evaluator, its V4 corpus, prompt-use receipts, and scorecards were retired with the custom Runtime.

Managed Harness evaluation is owned by the protected released-response flow and its audit/admission linkage. The remaining scenario, report, and run directories are retained only where they are consumed by those supported workflows.

Historical rationale for the retired V4 endpoint harness remains in [ADR-057](../docs/decisions/adr-057-evaluate-endpoint-behavior-with-a-versioned-scenario-harness.md).
