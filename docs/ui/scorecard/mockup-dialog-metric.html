About these figures

Channel rows are Amazon-attributed: Amazon credits a purchase to each channel the shopper saw within 14 days, so one purchase can count in two rows.

Deduplicated ROAS credits each purchase once, so it is the only return figure across channels.

TACoS divides ad spend by Vendor Central shipped revenue, two measurement systems. When Vendor Central is late, TACoS shows when its data last arrived and the rest of the page keeps its window. [fictional figures]
